# 요구사항 v0.5 — 구현 추적용 요약

사용자가 제공한 요구사항정의서 v0.5를 정리한 요약본입니다.
원문 전체를 복제한 문서가 아니며 설계 변경은 decisions.md에서 별도 추적합니다.

## 목적과 범위

5대 지수(KOSPI200, S&P500, EURO STOXX 50, Nikkei225, HSCEI)의
52주 후 수익률을 기본 GBDT와 다중 분위수 GBDT로 예측합니다.
판매 전 위험 점검, 판매 후 주간 모니터링, 상품별 4단계 경보와 독립 시스템을 구축합니다.
개별종목 ELS 및 기존 사내 시스템 직접 연동은 제외합니다. REST API 노출은 포함합니다.

| 요구사항 | 내용 | 현재 |
|---|---|---|
| FR-01 | 1992년 이후 지수·금리·환율·신용위험 데이터 외부 수집 | CSV/FRED 어댑터 구현, 실제 5지수 확보 미완료 |
| FR-02 | 주 단위 주기 정합·변화율 변환 | 구현 |
| FR-03 | LOCF 결측 처리 | 구현, 선행 결측 유지 |
| FR-04 | 선택 변수 자체 분포의 cVaR 기반 구간화 | 미구현, 알고리즘 상세 확정 필요 |
| FR-05 | expanding median/0 이진화, NSRPS ETC 선택 | 미구현 |
| FR-06 | 52주 후 수익률 타겟 | 미구현 |
| FR-07 | 지수별 기본 1 + 분위수 8 = 45개 모형 | 미구현 |
| FR-08 | 분위수 보간·worst-of·4단계 경보 | 미구현, 확률 정의 재검토 필요 |
| FR-09 | 주간 배치 모니터링 | 수동 데이터 배치만 구현 |
| FR-10 | 메인·상세·상품·이력·판매전 화면, 2권한, API | 미구현 |
| FR-11 | 상품 조건·기준가격·평가일·배리어·상태 관리 | 미구현 |

실행 순서는 FR-01 → FR-02/03 → FR-05 → FR-04 → FR-06/07입니다.
분위수는 0.01/0.05/0.10/0.25/0.50/0.75/0.90/0.95입니다.
ETC 동률은 왼쪽 우선, 선택 컷오프는 elbow 우선/상위 30% 대안입니다.
경보 임계값 5/15/30%는 검증 전 초기 설계입니다.

## 비기능 요구사항

- Expanding walk-forward 및 위기 국면 검증, 벤치마크 대비 개선
- API 재시도, 실패 시 LOCF·알림, 연속 실패 최신성 경고
- Best-effort 운영, API 키 분리, 내부 접근 및 조회/관리 권한
- 지수 목록 설정화, 예측·경보 DB 감사이력, SHAP 기여도
- 1인 + AI 지원, 8주, 로컬 Mac 학습

성능 수치 목표, 이력 보관 기간, 데이터 사용권·최초 확보일,
