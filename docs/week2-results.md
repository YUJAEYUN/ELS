## FR-04 실험 사양

원 요구사항은 기울기 안정의 수치 기준과 경계 수가 미정입니다.
따라서 아래는 **프로젝트 실험안**이며 정식 단조구간화 충족을 주장하지 않습니다.

- 선택된 수익률/차분 변수 자신의 하위 ES만 사용합니다. 레벨 변수 입력은 거절합니다.
- alpha=1%~25%, 1%p 간격, 꼬리 표본 질량 최소 10개.
- ES는 순서통계량에 부분 가중치를 적용해 정확히 alpha 질량을 평균합니다.
- 연속 3개 ES 기울기가 최대 절대 기울기의 25% 이하인 첫 지점을 선택합니다.
- 없으면 alpha=10%, 표본 수가 부족하면 최소 질량을 만족하는 grid로 대체합니다.
- 경계는 선택 alpha / 50% / (1-alpha)의 경험 분위수입니다. 중복 경계는 합칩니다.
- 타겟과의 단조 관계는 보장하지 않습니다. 기본 CLI에서는 구간화를 끄고,
  --experimental-bins를 지정한 경우에만 적용합니다.

NSRPS는 사용자 문서에 맞춰 인접 pair를 중첩 포함 집계하고, 왼쪽부터 비중첩 치환합니다.
동률은 첫 출현, 상수열에서는 즉시 종료합니다. 동일 심볼 pair의 중첩 빈도 정의가 다른
구현과는 점수가 다를 수 있어 외부 라이브러리와의 무조건적인 일치를 주장하지 않습니다.
