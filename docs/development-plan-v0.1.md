# 개발계획 v0.1 — 실행용 정리

사용자 제공 계획을 정리했습니다. 1인 + AI 지원, 8주 프로토타입입니다.
이번 초기 커밋은 1주차 구현이며 전체 8주 산출물 완료를 의미하지 않습니다.

| 주차 | 작업 | 완료 기준 |
|---|---|---|
| 1 | 환경·데이터 소스·FR-01~03 | 테스트/합성 데모 통과, 실제 데이터 커버리지 확인 |
| 2 | ETC/NSRPS·선택 변수 구간화 | 수작업 예제 및 fold 내 학습 검증 |
| 3 | KOSPI200 9개 모형·walk-forward | 라벨 성숙 시점 준수, 벤치마크 비교 |
| 4 | 5지수 45개 모형·위기 검증 | 시기별 RMSE/pinball/coverage 리포트 |
| 5 | 분위수·경보·상품마스터 | decisions.md 확률 정의 해결 후 구현 |
| 6 | Streamlit 5종 화면·REST API·기본 권한 | 상품 입력→조회 및 권한 테스트 |
| 7 | 주간 자동화·장애 대체·알림·SHAP | 실패 시나리오 및 이력 확인 |
| 8 | 통합검증·문서·회고 | 재현 가능한 실행, 한계·확장과제 명시 |

Python 3.11+, pandas/numpy, LightGBM, SHAP, SQLite, Streamlit,
requests 및 REST API용 FastAPI를 사용합니다.
학습·추론 주기는 분리해 결정하며 매주 무조건 재학습하지 않습니다.

## 미완료 데이터 의존성

- 5대 지수의 사용 가능한 벤더·라이선스·시작일 확정
- FRED 키 발급 후 실제 호출 검증, CDS/스프레드 가용성 조사
- 1992년까지 없는 자료는 역방향 채우기하지 않음
- 발표일·수정 빈티지 확보 여부 확인 후 백테스트 허용 범위 결정

## 검증 및 산출물

현재: 오프라인 단위/통합 테스트, 합성 5지수 주간 데이터, 소스·품질 메타데이터.
향후: 모델 45개 및 메타데이터, 백테스트 리포트, 대시보드, SHAP 예시.
보관 기간은 개인 프로젝트 초기 제안 3년(미확정)이며 자동 삭제는 구현하지 않습니다.
다중 호라이즌·운영 서버·React 전환은 확장 과제입니다.
